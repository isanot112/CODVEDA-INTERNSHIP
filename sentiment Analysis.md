# Social Media Sentiment Analysis with NLP

## Overview
A Python-based Natural Language Processing (NLP) project that cleans text data, classifies sentiments into Positive, Negative, or Neutral, and visualizes frequency trends using word clouds.

## Tools & Libraries
* **Python** (Pandas, NumPy)
* **NLTK** (Tokenization, Stopwords removal, Lemmatization)
* **TextBlob** (Polarity-based sentiment analysis)
* **Matplotlib, Seaborn, WordCloud** (Visualizations)

## Project Workflow
1. **Data Preprocessing:** Converted text to lowercase, removed punctuation and stopwords, and applied word lemmatization.
2. **Sentiment Classification:** Computed sentiment polarity scores (-1.0 to 1.0) to categorize comments.
3. **Data Visualization:** Plotted sentiment distribution counts and generated separate word clouds for positive and negative text.

## How to Run in Google Colab
1. Download the `.ipynb` notebook file from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook and run the cells sequentially.
